# Цифровой ассистент офтальмолога — полный обзор проекта

## 👁️ Видение проекта

Клиническая система поддержки принятия решений на базе ИИ для классификации заболеваний переднего отдела глаза, предназначенная для помощи офтальмологам и медицинским специалистам в раннем выявлении и диагностике распространённых глазных заболеваний.

## 📝 Резюме

### Что мы создали

Веб-приложение с полным циклом, использующее **глубокое обучение** для анализа снимков глаз и классификации их по 4 категориям:

| Класс | Медицинский термин | Арабский | Уровень риска |
|-------|--------------|--------|------------|
| Здоров | Нормальный глаз | عين سليمة | Низкий |
| Заболевание 1 | Конъюнктивит | التهاب الملتحمة | Умеренный |
| Заболевание 2 | Катаракта | المياه البيضاء | Умеренный |
| Заболевание 3 | Кератит | التهاب القرنية | Высокий |

### Постановка задачи

- **Клиническая потребность**: раннее выявление глазных заболеваний в условиях ограниченных ресурсов
- **Доступность**: обеспечение скрининга в отдалённых районах
- **Эффективность**: снижение нагрузки на офтальмологов с помощью скрининга на базе ИИ
- **Образование**: помощь студентам-медикам в изучении проявлений глазных заболеваний

### Подход к решению

1. **Ядро ИИ**: CNN на базе MobileNetV2, обученный на изображениях глазных заболеваний
2. **Веб-платформа**: адаптивное веб-приложение, доступное на любом устройстве
3. **Клиническая интеграция**: результаты с оценками достоверности и клиническими примечаниями
4. **Двуязычная поддержка**: английский и арабский для региональной доступности

### Поток данных

1. **Пользователь загружает снимок глаза** → фронтенд проверяет и отправляет в бэкенд
2. **Бэкенд получает изображение** → проверяет тип и размер файла
3. **Сервис ИИ обрабатывает** → выполняет препроцессинг изображения и инференс
4. **Возвращаются результаты** → предсказание с оценкой достоверности
5. **Запись в базу данных** → предсказание сохраняется для истории
6. **Фронтенд отображает** → показывает результаты с клиническим контекстом

## ✨ Основные возможности

### 1. Диагностика на базе ИИ
- **Загрузка изображений**: перетаскивание или выбор файла
- **Анализ в реальном времени**: время инференса ~1–2 секунды
- **Оценка достоверности**: расширенные метрики достоверности (маржа, энтропия)
- **Флаги безопасности**: предсказания с низкой достоверностью помечаются для проверки

### 2. Библиотека заболеваний
- **Подробная база данных**: детальная информация о каждом состоянии
- **Двуязычный контент**: описания на английском и арабском
- **Функция поиска**: фильтр по названию заболевания или симптомам
- **Клиническая информация**: симптомы, тревожные сигналы, полезные советы, когда обратиться к врачу

### 3. История предсказаний
- **Отслеживание случаев**: просмотр всех прошлых предсказаний
- **Фильтрация**: фильтр по типу заболевания
- **Управление**: удаление отдельных или всех записей

### 4. Образовательный контент
- **Обучение пациентов**: простые и понятные объяснения
- **Информация о безопасности**: чёткие дисклеймеры и предупреждения
- **Медицинское обучение**: полезно для студентов и ординаторов

## 🔑 Ключевые понятия

### 1. Инференс глубокого обучения
Модель ИИ принимает снимок глаза и выдаёт вероятности для каждого класса заболеваний.

### 2. REST API
Фронтенд общается с бэкендом через HTTP-запросы (GET, POST, DELETE).

### 3. ORM базы данных
SQLAlchemy абстрагирует операции с базой данных, делая код независимым от СУБД.

### 4. Паттерн «Singleton»
Модель ИИ загружается один раз и переиспользуется для всех предсказаний (экономия памяти).

### 5. Потокобезопасность
Корректные механизмы блокировки гарантируют, что параллельные запросы не повредят данные.
